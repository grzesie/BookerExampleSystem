# BOOKER EXAMPLE SYSTEM

A personal sandbox project for trying out new solutions and technologies.
It is a simple booking system, used as a realistic playground where new frameworks,
libraries and approaches can be tested in practice before using them elsewhere.
It is not intended for production use.

## Frameworks/technologies used so far

- xUnit
- Minimal APIs
- Testcontainers
- GitHub Actions (unit tests run automatically on every push and pull request)

## Plans

- API contracts

## Running unit tests

```
dotnet test
```
